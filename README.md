# 10-Minute Worksheets: AI and Machine Learning

Static site for the Binary Star worksheet series on AI and machine learning,
published at <https://ai-gen1991.github.io/ai-ml/>.
Everything here is generated by `../../build_aiml.py` (which reuses `build_site.py`);
edit those scripts, not the `.html` files.

Same design, sign-in, progress, likes, comments and admin dashboard as the
computer vision site; the mascot is Nova, an original pixel owl, with her owlet Dot.

## Update the site

1. Write or change a worksheet in `../RNN_Topic/` (same `tenmin` style as the CV sheets).
   Add a lecture with `\watchfirst{\video{https://youtu.be/ID}{Title}}` after `\makeheader`.
2. New topics: add the number to `MODULES` in `build_aiml.py`.
3. Run `python3 build_aiml.py`, then commit and push this folder.
